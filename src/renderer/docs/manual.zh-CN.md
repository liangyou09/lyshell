# LyShell 使用手册

> LyShell 是一款内置 MCP 服务端的 Windows 终端 —— 你的终端，也是 AI 的终端。
> SSH / Telnet / 串口 / 本地 PTY 一应俱全，并让 Claude Code 等 AI 客户端直接操控会话、传输文件、管理连接。

本手册覆盖 LyShell 的完整用法。左侧大纲栏可快速跳转章节；`Ctrl + 滚轮` 缩放正文，抓手工具可平移视图。

## 界面总览

| 区域 | 内容 |
|------|------|
| 左列 · 机柜轨 | 最左的图标列，切换九个面板（`Alt + 1…9`），会话槽位带在线 LED 读数 |
| 左列 · 面板 | 会话 / Agent / DeepSeek Harness / Codex / Claude / 环境变量 / 插件 / 网页 / 设置 |
| 终端列 · 页签条 | 浏览器式页签条提顶为窗口第一行，同时是窗口拖拽区 |
| 终端列 · 分屏 | 递归分屏树，可水平 / 垂直任意切分 |
| 会话面板底部 | LIVE 行终端读数（编码、列 × 行、缓冲行数）+ 快捷命令组 |

侧栏可收起（机柜轨顶部按钮），收起后留下一圈 L 形内框线，悬停点亮即可展开，还你全宽终端。

## 连接

### 连接类型

| 类型 | 关键参数 | 说明 |
|------|---------|------|
| SSH | 密码或私钥；端口 `22` | 支持 Shell 进入命令、心跳保活、双击克隆 |
| Telnet | 主机 + 端口 `23` | 完整 IAC 协商 |
| 串口 | COM 口，波特率 `115200`（9600–921600），8N1 | 自动检测可用端口 |
| 本地 PTY | cmd.exe / PowerShell | 可配工作目录、Shell 与环境变量 |

### 新建会话

1. 会话列表顶部点击 **+**，选择连接类型
2. 填写主机、端口、认证（密码或私钥路径）
3. 点击 **连接**，页签亮 🟢 即成功；配置同时保存进侧栏

- **Shell 进入命令**：网络设备需先 `shell` → `enable` 才能进 CLI 的，逐行写入即可，LyShell 按序自动发送
- **编码**：SSH 会话乱码时，编辑会话把 UTF-8 切换为 GBK / GB2312
- **摘要 / 使用说明 / 标签**：可选的会话备注，供自己和 MCP 客户端检索

### 连接状态

页签状态点：🟢 已连接 · 🔴 错误 · ⚪ 未连接 · 🔵 新输出。侧栏分组里的会话还会做 TCP 可达性探测，显示「TCP 可达 · 未连接」。

## 终端

### 页签

- **克隆会话** —— 双击页签左半侧，同配置再开一个新终端
- **克隆通道** —— 双击页签右半侧（仅 SSH），复用已认证的连接免重登
- **拖拽** —— 页签拖到分屏边缘即拆分为独立窗格，拖回窗格中央还原为页签
- **收缩** —— 页签条空间不足时 Edge 式逐个收缩（只缩不滚），悬停可见详情卡
- **关闭** —— ✕ 断开连接；关闭所有终端页签后该分屏回到空态命令屏。若窗格还停驻着文档页签（/ls 清点等），文档不弹回而是留在页签行，键盘直接交给命令屏；停驻的 dsh web / 网页 / MCP 审计面板则会自动弹回接管

### 分屏

`Ctrl + Shift + H` 水平分屏，`Ctrl + Shift + V` 垂直分屏。也可以直接拖页签 / 会话到目标边缘。分屏比例拖动分隔条调整，布局自动保存，重启还原。

### 复制、粘贴与搜索

| 操作 | 方式 |
|------|------|
| 复制 | 选中文本自动复制 |
| 粘贴 | 右键 |
| 搜索 | `Ctrl + F` 或鼠标中键；支持正则、区分大小写、全字匹配，可跨全部标签搜索 |

### 终端读数

会话侧栏底部 LIVE 行：点击「列 × 行」清屏（保留滚动历史）；点击缓冲行数滚回底部，双击清空回滚。读数还带协议码与字符编码（SSH / Telnet / 串口显示，本地终端走 ConPTY 恒为 UTF-8，不显示编码）。点击编码弹出选择框（UTF-8 / GBK / GB2312 三选一，当前项点亮），读写两个方向立即生效、只作用于本会话 —— 不写回保存的会话配置：同一会话重连保持当前编码，关闭后重新打开才回到保存值；已显示的乱码不会追溯修复，切换后新输出按新编码解码。

## 命令模式

无终端时，空分屏就是一块命令屏；有终端时 `Ctrl + Shift + P` 随时呼出全屏命令面板。输入 `help`、`/?` 或 `/` 即见全部命令（待命时输入框里就有这行提示），`↑↓` 选择、`Tab` 补全选中项、`Enter` 执行；输入为空时 `↑↓` 翻已执行命令的历史，命令名后按了空格则 `↑↓` 只翻这条命令用过的参数（子命令），召回后 `Enter` 重跑。带参数的命令（`/ls`、`/help`）在命令名后按空格即展开参数目录，同样 `↑↓` 选择、`Tab` 补全、`Enter` 执行；参数打错一两个字母也能就近落到想去的那条（`sesion` → `sessions`）。命令跑出的文档页签（`/ls` 清点、`/help` 手册）在空态下内联为命令屏的输出区：文档在上、输入框在下，键盘保持在命令屏 —— 点文档里的链接、工具条按钮或停驻页签的 ✕，输入焦点都不动，边看边敲下一条命令。

| 命令 | 作用 |
|------|------|
| `/help [chinese / english]` | 打开本使用手册；参数强制语言（`/help chinese` 展开中文说明），缺省跟随界面语言 |
| `/?` | 在输出区打印全部命令及简介（首行是标题与总数；子命令以树形勾线（`├`/`└`）列在所属命令之下、参数词琥珀点亮，与待命提示点名的 `help`、`/` 三入口同义） |
| `/new` | 新建连接（打开会话对话框） |
| `/ls [对象]` | 清点全部对象：会话、Agent、变量组、工作区、插件，以文档页签展示；行内名称可点击打开对应对象（会话 / Agent / 工作区为启动，变量组为编辑），各节带「新建」入口。带对象参数只看一类：`/ls env`、`/ls claude`（可用：sessions / agents / env / dsh / codex / claude / plugins / all，子清单是独立页签） |
| `/local` | 快速打开本地终端 |
| `/sessions` `/agents` `/dsh` `/codex` `/claude` `/env` `/plugins` `/web` `/settings` | 切换左侧对应面板 |

## 会话管理

- **置顶** —— 悬停会话卡片，点 📌
- **搜索** —— 搜索框按名称 / 主机 / 标签 / 用户过滤
- **分组** —— 会话按分组折叠展开；也可按协议（SSH / Telnet / 串口）过滤
- **浮窗** —— `Ctrl + \`` 从任意界面呼出会话浮窗，搜索回车即连
- **导出 / 导入** —— 侧栏底部按钮；支持 AES-256-CBC 加密，覆盖会话与快捷命令

## 快捷命令

会话面板底部的快捷命令条：右键 → **编辑分组**，添加如 `tail -f /var/log/syslog` 这类常用命令（支持多行与 `\n` `\xHH` 转义解析）。`Ctrl + F1`–`F12` 随处触发，侧栏收起时同样有效，发送目标是当前活动终端。最多 12 条 × 5 组，色点切换分组。

## 文件管理器

仅 SSH 会话可用，确保当前活动页签是 SSH 连接。

- **浏览** —— 文件面板即远端目录树，支持筛选（`*.log` 等）
- **上传** —— 从桌面直接拖拽到文件面板
- **下载** —— 双击远程文件，或右键 → 下载；完成后自动 MD5 校验
- **历史** —— 记录文件名、大小、路径、MD5，支持重新下载
- **传输通道** —— 独立 SSH 连接，不阻塞终端；SFTP 或 TCP-over-SSH 隧道，`AllowTcpForwarding` 禁用时也不会回退明文
- **下载目录** —— 默认 `~/Downloads/LyShell/`，可在设置中修改；可开启「按服务器自动创建子目录」归档

## 文档页签

在终端分屏内以页签形式阅读文档，与终端同框并排。

- **打开方式** —— 窗口拖放 `.md` / `.html` 文件、`Ctrl + Shift + O` 打开本地文档、终端内 `Ctrl + 点击` 路径、文件树双击远端文档
- **格式** —— `.md` / `.markdown` / `.txt` 渲染为 Markdown（代码高亮）；`.html` / `.htm` 以只读沙箱渲染
- **大纲栏** —— 有标题的 Markdown 自动生成目录轨，可拖宽、可整轨收起
- **缩放** —— `Ctrl + 滚轮` 调节，点击百分比复位
- **抓手** —— 工具栏抓手按钮按住拖动平移视图（Markdown 也可随时中键拖拽）
- `/help` 打开的正是这样一个文档页签

## 网页页签

左侧 **网页** 面板是轻量内置浏览器，看监控大盘和文档再合适不过。输入网址（无 scheme 自动补 `https://`）回车，即以普通页签打开在当前活动分屏 —— 拖拽拆分、页签语义与终端完全一致，大盘可以和喂数据的终端同框。

- **最近访问** —— 成功加载过的 URL 自动记住（去重、封顶 30 条），输入框原生补全；点击重开、✕ 删除单条
- **安全** —— 仅放行 `http` / `https`；webview 导航与弹窗由主进程走专属 partition 分流锁定

## AI Agent

Agent 启动栏与 Agent 无关 —— 不绑定任何 AI 工具。任意 CLI 工具都能注册：名称、命令、图标、工作目录、环境变量。按下即在一个**瞬态终端**里启动，完整回滚、分屏、输入法一视同仁；关闭页签即消失，不残留。

Agent 可绑定一个环境变量组（见下节），凭据集中管理。

## DeepSeek Harness 工作区

`dsh`、`codex`、`claude` 在 Harness 面板中是一等公民：各自独立左侧页签、专属工作区列表、依赖检测。

### 工作区

一个工作区 = 一个目录 + 一份配置。可设模型（启动时以 `--model` 传入）、备注，并可绑定变量组或跟随全局启用的变量组。Claude 工作区另有「跳过权限确认」开关（启动时附加 `--dangerously-skip-permissions`）。

### worktree 目录隔离

让多个 agent 指向同一仓库而互不踩踏：工作区切到 worktree 隔离后，在 `<仓库根>/.lyshell-worktrees/<key>` 的专属 git worktree、`lyshell/<key>` 分支上启动 —— 首次启动创建，此后复用，**未提交修改跨启动保留**。删除工作区不会动它的 worktree。

- **私有（默认）** —— 自动生成可读 key（如 `claude-myapp-20260708-160745`），每工作区独立检出
- **共享** —— 显式指定 key，同名工作区跨 dsh / codex / claude 共用同一检出与分支，彼此实时可见改动

### 启动方式

- **终端 TUI** —— `dsh-tui` 等作为标准终端页签运行
- **内嵌 Web UI** —— 以 `dsh web --port 0` 启动，LyShell 解析真实端口后渲染进应用内 `<webview>` 页签；回环锁定 + URL 校验
- 两者可**同框并排**：把 Web UI 页签拖到分屏边缘即可，拖回中央还原

### 依赖检测

CLI 依赖在应用启动时统一检测一次（三个 agent 并行）并缓存，切页签即时读取。缺失时面板指出缺什么、给出一行安装命令与仓库链接，但不会替你安装。**重新检测**按钮强制重扫；PATH 从注册表实时读取，新装 CLI 无需重启即可识别。

## 环境变量组

预配置具名的 `KEY = VALUE` 集合，供 Agent 与工作区引用，密钥录入一次、切换环境无需逐个工作区改动。

- **全局单选** —— 同一时刻至多启用一组；点击已启用的一组即停用，落回「系统环境变量」
- **核心字段** —— Base URL 与 API Key 按 agent 映射注入：dsh → `DEEPSEEK_BASE_URL` / `DEEPSEEK_API_KEY`，codex → `OPENAI_BASE_URL` / `OPENAI_API_KEY`，claude → `ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN`
- **附加变量** —— 其余配置（如 `CODEX_HOME`、`NO_PROXY`）原样注入
- **codex 特例** —— 启动前把 `OPENAI_BASE_URL` 写入 `$CODEX_HOME/config.toml`（Rust 版 codex 不读该环境变量）；行级手术式编辑、幂等、原子，首次修改前自动备份 `.bak`
- **打码** —— 敏感值（`*_KEY`、`*_TOKEN` 等）默认打码，点眼睛按钮明文展示

## MCP 集成

LyShell 内置 MCP 服务端，让 Claude Code 等外部 AI 客户端通过 MCP 协议操控终端：列出会话、发送命令、读取输出、传输文件、管理连接。

### 注册

设置 → MCP 提供 JSON / 命令 / TOML 三种注册格式，适配不同客户端。多数情况下无需手动配置：从 Agent 启动栏启动 agent，让它自己把 LyShell 配成 MCP 服务端即可。

### 工具与能力

| 能力 | 工具 |
|------|------|
| `read` | `list_sessions` · `read_output` · `read_file` · `stat_file` · `list_files` · `read_session_notes` · `wait_for_prompt` · `tail_until` |
| `interactiveWrite` | `send_input` · `send_and_wait` |
| `execute` / `localExecute` | `execute_command`（仅 SSH）· `run_on_sessions`（广播，最多 50 会话并发 10） |
| `fileWrite` | `upload_file` · `download_file` |
| `sessionControl` | `create_session` · `reconnect_session` · `close_session` · `open_connection_dialog` |
| `sessionMetadataWrite` | `write_session_notes` |

### 安全机制

- **会话级授权** —— 每个终端独立权限范围，全局 token 与会话 token 分离
- **能力门控** —— 每个端点服务端强制校验
- **破坏性命令确认** —— 对 `rm -rf /`、`dd` 写块设备、fork bomb 等疑似灾难命令弹人工确认闸
- **共享 PTY 锁定** —— MCP 占用终端时人工输入被阻塞，页签标注「MCP 正在使用此终端」
- **审计面板** —— MCP 活动全量留痕，以页签形式打开，日历选择器 + 过滤 + 分页

> 已知限制：全屏 TUI 应用（vim、htop、less）不支持 MCP 操作 —— ANSI 剥离后交替屏幕为乱码。请用 LyShell 原生终端。

## 插件与 Python 脚本

### 插件系统

权限门控的插件宿主，支持 **Python**（一次性 / 常驻）与 **Node.js**（常驻）插件，可从本地目录、ZIP 或远程 URL 安装。每个插件独立授权，细粒度权限（读取 / 写入 / 执行 / 文件 / 会话控制）服务端校验，含路径安全、破坏性命令确认、共享终端锁定。示例见仓库 `examples/` 目录。

### Python 脚本引擎

内置 Python 执行引擎，提供 `LyShell` API 驱动终端自动化：

```python
session = LyShell.get_current_session()
LyShell.execute("ls -la")
LyShell.send("hello\n")
LyShell.wait_for("prompt$")
```

脚本运行时可读 `LYSHELL_SESSION_ID`、`LYSHELL_SESSION_TYPE`、`LYSHELL_HOST`、`LYSHELL_PORT` 环境变量。Python 解释器自动检测系统 PATH，可在设置中配置。长驻或定时任务建议改用 Node.js 插件。

## 常见问题

**SSH 连接后中文乱码？**
编辑会话，编码从 UTF-8 切换为 GBK 或 GB2312。

**串口连接后无输出？**
确认端口号与波特率正确 → 检查设备管理器中端口未被占用 → 部分设备需回车激活。

**文件管理器不显示？**
仅 SSH 会话可用，确保当前活动页签是 SSH 连接。

**Ctrl+\` 浮窗不生效？**
快捷键仅在 LyShell 获得焦点时拦截（窗口级，不劫持系统），确认 LyShell 在前台。

**下载的文件在哪？**
默认 `~/Downloads/LyShell/`，可在设置中修改。
