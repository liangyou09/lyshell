# braille-punch（demo · 第一人称 3D 出拳）

盲文点阵 3D 出拳效果。验证字符渲染能做到"3D 打击感"到什么程度。

POV 视角：一只红色拳套 + 前臂悬在身前（收势位），按组合拳节奏（直拳/左刺/右勾）向观察者突刺——透视下越近越大，击中瞬间屏震 + 爆闪 + 粒子迸射，再收回。纯程序生成、零素材，接 braille-wave 的 heredoc 远程投递管线。

## 诚实预期

160×96 点分辨率下，它读作"一个红色拳套朝你脸砸过来"，**不是** Fight Night 级别的人形——是风格化的终端艺术。但 3D 深度（透视放大）、打击感（屏震/爆闪/粒子）、节奏感（组合拳编排）都出来了。

## 效果细节

- **拳套**：球面点云，法线 · 光向算明暗，真彩色暗红→亮红 6 级量化。
- **前臂**：圆柱点云，从拳套向摄像头延伸并收细，肤色着色。
- **出拳轨迹**：收势位 → 微后拉 → 刺出（越近越大）→ hold 击中 → 收回。
- **击中瞬间**：屏震 + 爆闪 + 34 个粒子向外/向摄像头迸射。
- **组合拳**：每 1.8s 一拳，直拳/左刺/右勾轮换。
- 78×22 盲文单元 = 156×88 点，~20fps，18s 后自动还原终端。

## 依赖

- 远程主机有 `python3`（纯标准库）。
- LyShell 里有已连接的 SSH 会话。

## 安装与触发

1. Plugins ->「+ dev」选 `examples/braille-punch/`。
2. 确认 `read`/`interactiveWrite` 两项权限，安装。
3. 连一个 SSH 会话（停在提示符），勾启用 -> 远程终端里放 18s 出拳动画，自动还原。

**作用范围**：所有已连接、停在 shell 提示符的 SSH 会话各放一遍。vim/htop/跑命令的会话被安全门跳过（日志可见）。

## 可调旋钮

`render.py` 顶部常量：

- `FOCAL`：焦距，越大透视越强（近处更大）。
- `RG`：拳套半径。
- `CYCLE`：每拳周期（秒）。
- `DURATION`/`FPS`：时长与帧率。
- `punch()` 里 `gz/sz/sx/sy`：收势位与各拳型刺出位。
- `shade_glove`/`shade_arm`：颜色与明暗映射。

## 文件

- `lyshell-plugin.json` - 清单（runtime=node，capabilities=read/interactiveWrite）。
- `main.js` - 列 SSH 会话、过提示符门、heredoc 投递 render.py（与 braille-wave 同构）。
- `render.py` - 3D 出拳：点云拳套+前臂、透视投影、真彩明暗、屏震/爆闪/粒子、组合拳编排。
