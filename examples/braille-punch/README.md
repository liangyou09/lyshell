# braille-punch（demo · 第一人称 3D 出拳）

盲文点阵 3D 出拳效果。验证字符渲染能做到"3D 打击感"到什么程度。

POV 视角:一只红色拳套 + 前臂悬在身前(收势位),按组合拳节奏(直拳/左刺/右勾)向观察者突刺--透视下越近越大,击中瞬间屏震 + 爆闪 + 粒子迸射,再收回。纯程序生成、零素材,接 braille-wave 的 heredoc 远程投递管线。

## 诚实预期

160×96 点分辨率下,它读作"一个红色拳套朝你脸砸过来",**不是** Fight Night 级别的人形--是风格化的终端艺术。但 3D 深度(透视放大)、打击感(屏震/爆闪/粒子)、节奏感(组合拳编排)都出来了。

## 效果细节

- **拳套**:球面点云(fib 球面 150 点),法线 · 光向算明暗,真彩色暗红→亮红 6 级量化。
- **前臂**:圆柱点云,从拳套向摄像头延伸并收细,肤色着色。
- **出拳轨迹**:收势位(下中、远、小)→ 收势微后拉 → 刺出(向脸中心收敛、近、大)→ hold 击中 → 收回。smoothstep 缓动。
- **击中瞬间**(进入 hold 的一帧):屏震(全帧随机偏移,0.82 衰减)+ 爆闪(拳套位置同心亮环,0.86 衰减)+ 34 个粒子向外/向摄像头迸射(0.90 衰减)。
- **组合拳**:每 1.8s 一拳,直拳/左刺/右勾轮换(刺出位置与深度不同)。
- 78×22 盲文单元 = 156×88 点,~20fps,18s 后自动还原终端。

## 依赖

- 远程主机有 `python3`(纯标准库)。
- LyShell 里有已连接的 SSH 会话。

## 安装与触发

1. Plugins ->「+ dev」选 `examples/braille-punch/`。
2. 确认 `read`/`interactiveWrite` 两项权限,安装。
3. 连一个 SSH 会话(停在提示符),勾启用 -> 远程终端里放 18s 出拳动画,自动还原。

**作用范围**:所有已连接、停在 shell 提示符的 SSH 会话各放一遍。vim/htop/跑命令的会话被安全门跳过(日志可见)。

## 工作原理

与 braille-wave 同构,核心差异在 render.py:

```
render_frame(t, st):
  ├─ thrust_for(tp)         编排:收势→刺出→hold→收回(smoothstep)
  ├─ punch(thrust, kind)    拳套世界坐标(guard→strike 收敛向摄像头)
  ├─ 进入 hold 瞬间 -> st.shake/flash/粒子 触发
  ├─ 收集点(拳套球 + 前臂柱 + 粒子),按 z 升序(远先画,近覆盖)
  ├─ project():透视投影 x*s+cx, s=FOCAL/(-z)  越近 s 越大 -> 越大
  ├─ 点 -> 盲文格(设点 bit + 整格真彩色)
  ├─ 爆闪:拳套屏幕位置叠同心亮环
  └─ 网格 -> bytes(空格/真彩色转义+盲文字节)
```

两个关键不变量(沿用 braille-wave):

1. **render.py 零反斜杠**:ESC/换行用 `bytes([27])`/`bytes([10])`,真彩色用 `b'[38;2;%d;%d;%dm' % (...)`。send_input 的转义处理器对本体是 no-op,heredoc 体逐字到远程。
2. **heredoc 定界符加引号** `<<'LYSHELL_PUNCH'`:禁展开,本体逐字传入。

## 可调旋钮

`render.py` 顶部常量:

- `FOCAL`:焦距,越大透视越强(近处更大)。
- `RG`:拳套半径。
- `CYCLE`:每拳周期(秒)。
- `DURATION`/`FPS`:时长与帧率。
- `punch()` 里 `gz/sz/sx/sy`:收势位与各拳型刺出位。
- `shade_glove`/`shade_arm`:颜色与明暗映射。

## 扩展方向

- **第三人称双人对打**:侧视图,两个点云人形,一个出拳弧线、命中、对方击退。比 POV 难读(低分辨率下人形辨识度低),但更像"打拳"。
- **交互出拳**:render.py 读 stdin,按 `j/k/l` 出不同拳--插件经 send_input 发按键即可触发(终端本地读 stdin,MCP 不参与输入回路)。
- **多终端墙**:把 POV 场景按视口切片投到多个终端拼成大画布(共享时钟同步)。

## 文件

- `lyshell-plugin.json` - 清单(runtime=node,capabilities=read/interactiveWrite)。
- `main.js` - 列 SSH 会话、过提示符门、heredoc 投递 render.py(与 braille-wave 同构)。
- `render.py` - 3D 出拳:点云拳套+前臂、透视投影、真彩明暗、屏震/爆闪/粒子、组合拳编排。零反斜杠。
