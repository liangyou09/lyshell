# 只读网页副本深睡：实现与验收

日期：2026-10-28。工作目录 `D:/workspace/claude/LyShell`，main 基线 `83053c4e2bbabdbbfd3bca45aa8fd75ffdd54b58`。本轮没有切换 worktree，没有修改旧特性目录，没有提交、推送或打包发布。

## 支持范围

普通动态网页自动深睡仍不支持。Electron 43.7.11 的 webview 在触发 `will-prevent-unload` 后仍会销毁；CDP 的 beforeunload 对话框明确回复拒绝也不能阻止销毁。普通 BrowserWindow 对照可以保活。三轮、12 种实验的结果见 [安全关闭证据](safe-close-probe-results.json)，脚本为 `scripts/shelf-memory-p0/safe-close-probe.cjs`。这不是可被放行 beforeunload 修复的问题。

新能力仅面向用户主动选择的**独立只读副本**：网页访问栏“更多”→“打开只读副本（可休眠）”。原网页保留；副本使用独立、内存态的 `shelf-readonly-v1:<uuid>` 分区，不继承原网站登录状态。界面明确标出脚本、编辑、提交和媒体停用。用户选择该模式意味着接受此副本可丢弃，后续打开会重新访问 URL；仅应对可以重复读取的网址使用，不能把 HTTP GET 本身当成业务无副作用的证明。

副本先收纳至任务保存区，且无真实展示需求、闲置五分钟，才进入候选检查。没有收纳的副本继续保活。默认打开的网页、POST、插件、Agent/Harness、终端/PTY/SSH/Telnet/串口均不进入该路径。动态应用可能在只读模式中内容缺失，使用原网页即可回退。

## 可核验的契约

- 主进程在创建前安装专用 Session 的请求、响应头、权限和下载闸门。只接受 GET、HTTP(S) 与文档/样式/图片/字体；文档地址不接受查询参数、片段或内嵌凭据，最终保存地址沿用既有 `shelfWebUrl` 脱敏规则。HTML、纯文本、XHTML 以外的主文档拒绝，PDF/媒体/内置查看器不在支持范围。
- 每个响应独立追加 CSP，不删除站点已有策略：`script-src 'none'`、`form-action 'none'`、禁止子框架、对象、Worker、连接和媒体。所有权限和下载拒绝。
- 实测 `javascript:false` 以及 CSP sandbox 缺少 `allow-scripts` 均不能完成隔离 preload 握手。因此此版本的 WebPreferences 保留 JavaScript 执行引擎，**页面脚本由主进程追加的 CSP 禁止**；`sandbox allow-same-origin allow-scripts` 仅让应用的隔离 preload 能工作。不能把 WebPreferences 的 `javascript:true` 描述为关闭了 JavaScript，也不能把单独的参数设置当成保护证据。
- 每个只读资源使用独立 Session，恢复保持原 Session/分区。原生 attach 根据 main 安装的 Session 身份配对，再向隔离 preload 发挑战；不能依赖进程复用后可能残留的 argv 许可。握手晚于导航结束时也完成缩放/滚动和真实槽位收尾。
- preload 不暴露 contextBridge。它禁用表单/文件控件、移除 contenteditable，拦截编辑/粘贴/拖入/提交；实际输入/变化只能上报 blocked。应用只接受实际 guest、主框架、许可与随机文档 nonce 匹配的握手/滚动消息，网页不能授权 safe。
- 主进程验证已安装闸门的 Session 对象身份、安全偏好和当前实例/导航；加载、错误、崩溃、发声、DevTools/调试器、意外编辑均不放行。打开过 DevTools 的文档即便关闭检查器也继续保活，避免残留注入状态。unknown/blocked 均保活。

## 保存、关闭与恢复

主进程持有生命周期、原生句柄及最多 100 条有界诊断。候选刷新保护证据（有效期 2 秒），创建 `suspendOperationId`，保存最终 URL、任务/资源身份、格式版本/时间、原分区、缩放和尽力获取的滚动位置。保存区仓库按 revision 校验并原子替换文件；保存失败不关闭。落盘后再次核对需求、实例、导航、保护版本、电源 epoch 和已保存的 operation ID，才请求关闭。

通用 `safeCloseSupported` 仍为 false；只有 main 核验的可丢弃契约能走独立准入。没有强制放行 beforeunload，没有用 React 卸载关闭活 guest。只有匹配原生 `destroyed` 才提交 sleeping，随后 UI 才移除已销毁的元素。关闭超过 5 秒保持 `suspending` / `close-unconfirmed` 和原句柄，不发替代许可；迟到销毁仍按原 operation 核验。出现拒绝则本导航保活，不靠定时刷新绕过冷却。

主区与明确卡片选择/本次激活产生的有效需求才能恢复；滚动、补图、普通卡片挂载不唤醒。沿用 renderer 恢复队列的 1 并发、16 待处理、4 自动驻留限制，另在 main 对睡眠恢复的真实创建/导航限并发 1，实际 `did-stop-loading` 才释放原生槽。UI 超时不证明真实导航结束。销毁后释放自动驻留记录。

恢复沿用该资源原始的 `shelf-readonly-v1:<uuid>`、保存的最终地址与缩放。滚动命令绑定 preload 随机文档 nonce，最多 3 次、2 秒；用户输入或页面主动滚动中止。导航、锁屏/休眠/唤醒和宿主显示边界会失效旧证据/期限；唤醒后重新等待五分钟，不批量补睡。没有承诺恢复 JS 堆、表单、sessionStorage、WebSocket 或远端任务，也没有重放 shell、POST、任务或审批。

## 回退与未验证边界

### 2026-10-29 首帧补认修复

继续排查发现，首帧输入门槛原先仅监听 `dom-ready`，快速页在监听安装前发出该事件时，没有后续补认。新增回归测试在未修复代码上失败，证明该路径存在；但历史基准失败没有足够的事件日志，仍不能断言它就是那一次失败的原因。

修复在监听安装时补查已附着且已停止加载的 HTTP(S) 文档，并在 `did-stop-loading` 再补查。空白/POST 引导页、未附着页和仍在加载的页不补认。补认仍走截图与 main 实例/导航/几何核验，失败继续禁止输入；加载遮罩也补查同一文档，避免内容已经可用却永久显示加载中。没有自动点击“显示当前页面”、绕过原生核验或重建 guest。

本次新增 5 个用例，首帧/几何/网页模式共 73 个测试通过，类型检查、两份变更文件 ESLint、构建与完整应用 GUI 的休眠/恢复验收通过。该修复仅改 renderer 首帧事件处理；前文三轮内存/时延证据及源码摘要保留为修复前构建的实测，**没有将旧构建的时延当作修复后重新测得的结果**。尚未凭该修复消除历史首屏超时的所有可能原因。

Electron 会缓存创建过的 Session，因此单次应用进程最多登记 100 个只读分区；恢复沿用已登记分区不增加计数。预算耗尽时明确拒绝新副本，重启可重置，不能无限创建原生 Session 获取表面上的句柄回稳。

只读 Session 在授予创建许可前应用当前浏览器代理；不会为生产副本绕过用户代理。性能 fixture 使用隔离档案中的显式直连配置。副本不继承原网页登录状态，保留原网页并打开副本会先增加内存，独立 Session 本身也有活跃成本。

`LYSHELL_SHELF_READONLY_SLEEP=0` 关闭只读副本自动深睡，保留只读隔离与任务记录。全局 `LYSHELL_SHELF_BROWSER_LIFECYCLE=0` 时拒绝新的只读副本请求，不能悄悄降级成可执行脚本的普通网页。已有睡眠记录仍有显式打开入口。开关不会反转分类或重放任务。

尚未据此承诺任意网站的自动深睡、跨平台可撤销关闭、真实网站业务正确性、硬件中文 IME、混合 DPI/多屏、低内存设备表现或长时间系统级锁屏/休眠稳定性。电源边界已用注入事件/状态测试覆盖，不等同于实际整机睡眠验收。没有引入 Rust，也没有修改终端历史或连接所有权。
