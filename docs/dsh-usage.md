# DeepSeek Harness 用量与费用

启动面板提供四个范围：**会话 / 今日 / 过去7天 / 30天**。

- 会话：全局最近有用量的会话，标题会显示在统计下方；可能来自其他工作目录。
- 今日：本机当天零点至今的活动。
- 过去7天和30天：包含今天的最近7个、30个自然日。跨天会话只统计窗口内用量，会话数按整个窗口去重。
- 峰谷时段：统一使用北京时间；高峰为周一至周五09:00–12:00、14:00–18:00，中国法定节假日除外，其余时段全天按空闲档。周末补班不改变空闲档。

统计区在同一宽度下保持固定高度：常规550px，250px以内的窄容器600px，210px以内780px，以容纳字号较大的英文和30天费用图。未展开的正常统计不会出现内部滚动条；展开明细后在区域内滚动，不因范围切换改变上方启动区的布局。矮窗口仍可滚动整个启动页。

主读数显示预估费用和总token。输入缓存命中率、四类token、请求/轮次数保持可见；7/30天范围额外显示每日费用图。可点选日期，或聚焦图中日期后使用左右方向键、Home、End查看日期；图中只保留一个Tab停靠点。数字悬停可查看完整token数。

“高峰 / 空闲明细”分别显示两档的未缓存输入、缓存读取、缓存写入、输出、总token与费用。“计费说明”显示价格来源、模型路由、目录及范围说明。“计费设置”打开本机价目表。

费用按本地日志和每百万token的单价估算，实际扣费以平台账单为准。未知读数显示“—”；部分模型缺价时，金额使用“≥”并说明尚未定价的模型。日志残缺及未覆盖年份的节假日会单独提示。

目前内置日历覆盖2026年；价格文件中的holidays可补充日期。内置人民币单价仅与CNY/RMB配置合并，其他币种需自行配置价格。显式覆盖高峰价但未提供空闲价的路由，空闲时段采用覆盖后的高峰价；空白模板保留官方峰谷价格。

界面沿用全局主题与系统字体，用5px范围切换容器、3px选中项以及等宽数字区分信息层级。中文数值字号为28px费用、23px总token，窄栏为25px/21px；11px标签、12px重点读数。英文标签与明细为12px，费用/总token为30px/24px，窄栏为28px/23px。图表2px圆角用于数据几何，不修改其他面板设计系统。

实现入口：`src/renderer/components/Layout/DshUsagePanel.tsx`；统计与计价：`src/main/dsh/usage-service.ts`、`pricing.ts`、`tariff.ts`、`calendar.ts`。
