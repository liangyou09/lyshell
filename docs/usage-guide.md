## 1. 概述

LyShell 是一款基于 Electron + React + xterm.js 构建的智能终端软件，主要特性包括：

| 特性 | 说明 |
|------|------|
| **多协议连接** | SSH、Telnet、串口、本地终端 |
| **分屏终端** | 任意水平/垂直分屏，支持拖拽拆分与标签交换 |
| **快速命令** | 可分组管理的快捷命令栏，支持快捷键触发 |
| **文件管理** | 内置 SFTP/SSH 文件浏览器，支持上传下载与进度追踪 |
| **AI Agent** | 一键启动 Claude Code、Aider、Copilot 等 AI 工具 |
| **Python 脚本** | 内置 Python 引擎，可编写自动化脚本操作终端 |
| **浮窗快捷连接** | 全局快捷键呼出浮窗，快速连接会话 |
| **数据安全** | AES-256-CBC 加密导出，保护敏感连接信息 |

## 2. 安装与构建

### 环境要求

- Node.js ≥ 18
- Python 3（node-gyp 编译原生模块）
- Windows: Visual Studio Build Tools（C++ 桌面开发工作负载）
- macOS: Xcode Command Line Tools
- Linux: build-essential, libx11-dev 等

### 开发模式

```bash
# 安装依赖
npm install

# 编译原生模块（serialport, node-pty）
npm run rebuild

# 启动开发模式
npm run dev
```

### 生产构建

```bash
# 仅编译代码
npm run build

# 打包为安装程序（Windows）
npm run dist:win

# 打包为安装程序（macOS）
npm run dist:mac

# 打包为安装程序（Linux）
npm run dist:linux
```

### 打包产物

| 平台 | 格式 | 架构 |
|------|------|------|
| Windows | NSIS 安装包 (.exe) + 便携版 | x64 |
| macOS | DMG 镜像 | x64 + arm64 |
| Linux | AppImage + .deb | x64 |

## 3. 连接管理

点击侧边栏顶部的 **"+"** 按钮创建新会话，支持四种连接类型：

### 3.1 SSH 连接

SSH 是最常用的远程连接方式，基于 ssh2 库实现。

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 主机 (Host) | 目标服务器地址 | - |
| 端口 (Port) | SSH 端口 | 22 |
| 用户名 | 登录用户名 | - |
| 密码 | 密码认证 | - |
| 私钥 | 私钥认证（支持 passphrase） | - |
| Shell 进入命令 | 连接后自动执行的命令序列，每行一条，按顺序执行 | - |
| Shell 进入等待 | 执行 Shell 进入命令后的等待时间（毫秒） | 1000 |
| Keepalive 间隔 | SSH 心跳包间隔（秒） | - |
| 连接超时 | 连接就绪超时时间（毫秒） | - |

**典型场景 — 网络设备登录：**

对于需要先输入 `shell`、`enable` 等命令才能进入 CLI 的网络设备，可配置 Shell 进入命令：

```
shell
enable
```

LyShell 会按顺序自动发送每行命令，并在每条命令之间等待指定时间。

**会话克隆：**

- 双击标签页左侧：克隆会话（建立新的 SSH 连接）
- 双击标签页右侧（仅 SSH）：克隆通道（共享同一 SSH 连接，无需重新认证）

### 3.2 Telnet 连接

基于原始 TCP Socket 实现，完整支持 Telnet 协议（IAC 协商）。

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 主机 (Host) | 目标服务器地址 | - |
| 端口 (Port) | Telnet 端口 | 23 |
| 超时时间 | 连接超时（毫秒） | - |

### 3.3 串口连接

基于 serialport 库，用于连接串口设备（路由器、交换机、嵌入式设备等）。

| 参数 | 说明 | 可选值 | 默认值 |
|------|------|--------|--------|
| 串口路径 | COM 端口 | COM1, COM2, ... | - |
| 波特率 | 通信速率 | 9600, 19200, 38400, 57600, **115200**, 230400, 460800, 921600 | 115200 |
| 数据位 | 每帧数据位数 | 5, 6, 7, **8** | 8 |
| 停止位 | 停止位数量 | **1**, 2 | 1 |
| 校验位 | 奇偶校验 | **none**, even, odd, mark, space | none |

> 创建串口会话时，可从下拉列表中选择系统检测到的可用 COM 端口。

### 3.4 本地终端

基于 node-pty 实现，在应用内打开本地 Shell。

| 参数 | 说明 | 默认值 |
|------|------|--------|
| Shell 路径 | 可执行文件路径 | Windows: `cmd.exe`，macOS/Linux: `$SHELL` |
| 工作目录 | 启动目录 | 用户主目录 |
| 环境变量 | 额外的环境变量 | - |

## 4. 终端使用

LyShell 使用 xterm.js 渲染终端，支持完整的 ANSI 转义序列和 256 色。

### 4.1 终端搜索

| 操作 | 说明 |
|------|------|
| **Ctrl + F** | 打开搜索栏 |
| **鼠标中键** | 打开搜索栏 |
| 正则表达式 | 搜索栏中勾选 "Regex" 启用 |
| 区分大小写 | 搜索栏中勾选 "Case" 启用 |
| 全标签搜索 | 搜索栏中勾选 "All" 可搜索所有打开的终端 |
| 输入高亮 | 输入时实时高亮匹配内容 |

搜索栏支持拖拽移动，不遮挡终端操作。

### 4.2 终端设置

通过标题栏的 **齿轮图标** 打开设置面板：

| 设置项 | 范围 | 默认值 |
|--------|------|--------|
| 回滚行数 (Scrollback) | 1000 ~ 100000 | 10000 |
| 字体大小 (Font Size) | 8 ~ 32 | 16 |
| 光标闪烁 (Cursor Blink) | 开/关 | 开 |

### 4.3 编码设置

每个会话可独立设置终端编码，支持：

- **UTF-8**（默认）— 现代服务器标准编码
- **GBK** — 中文 Windows / 旧版 Linux 常用编码
- **GB2312** — 简体中文编码

编码在创建或编辑会话时配置，连接后自动应用。

### 4.4 启动命令

每个会话可配置 **启动命令 (Startup Commands)**，连接建立后自动逐行执行。适用于：

- 自动登录后执行环境初始化脚本
- 切换到特定工作目录
- 加载环境变量
- 网络设备自动进入特权模式

配置方式：编辑会话 → 启动命令文本框中输入，每行一条命令。

## 5. 分屏与标签管理

LyShell 支持灵活的分屏布局和标签管理。

### 分屏操作

| 操作 | 说明 |
|------|------|
| **Ctrl + Shift + H** | 水平分屏 |
| **Ctrl + Shift + V** | 垂直分屏 |
| 拖拽标签页到面板边缘 | 分屏（蓝色高亮 = 分屏，绿色 = 反转方向，橙色 = 交换标签） |
| 拖拽分隔线 | 调整分屏比例（10% ~ 90%） |

### 标签操作

| 操作 | 说明 |
|------|------|
| 单击标签 | 切换到该会话 |
| 双击标签（左侧） | 克隆会话 / 重新连接 |
| 双击标签（右侧，仅 SSH） | 克隆通道（共享 SSH 连接） |
| 拖拽标签 | 在同面板内重排序 |
| × 按钮 | 关闭标签 |

### 标签状态指示

- 🟢 **绿色** — 已连接
- 🔴 **红色** — 连接错误
- ⚪ **灰色** — 未连接
- 🔵 **蓝色高亮** — 非活动标签有新输出

分屏布局会自动保存，重启应用后恢复。

## 6. 快速命令

快速命令栏位于窗口底部状态栏中，提供一键执行常用命令的能力。

### 基本操作

| 操作 | 说明 |
|------|------|
| 单击命令按钮 | 在当前终端执行命令 |
| 右键单击命令按钮 | 编辑该命令 |
| 双击空白区域 | 添加新命令 |
| 右键单击分组选择器 | 批量编辑分组 |

### 命令分组

快速命令按分组管理，状态栏左侧可切换分组：

- 最多支持 5 个分组（1 默认 + 4 自定义）
- 每个分组最多 12 条命令
- 每个分组可设置名称和颜色标识

### 快捷键

| 快捷键 | 说明 |
|--------|------|
| **Ctrl + F1** ~ **Ctrl + F12** | 执行当前分组中的第 1~12 条命令 |

### 预置命令分组

LyShell 提供了三个预置命令分组：

**系统管理：**
| 命令 | 内容 |
|------|------|
| 查看系统信息 | `uname -a` |
| 查看磁盘空间 | `df -h` |
| 查看内存使用 | `free -m` |
| 查看CPU信息 | `cat /proc/cpuinfo \| grep "model name"` |

**网络工具：**
| 命令 | 内容 |
|------|------|
| 查看网络连接 | `netstat -tuln` |
| 查看IP地址 | `ip addr show` |
| 测试端口连通 | `nc -zv ${host} ${port}` |

**日志查看：**
| 命令 | 内容 |
|------|------|
| 实时系统日志 | `tail -f /var/log/syslog` |
| 查看最近日志 | `tail -100 /var/log/syslog` |

## 7. 文件管理器

文件管理器嵌入在侧边栏底部，仅对 **SSH 会话** 可用。

### 7.1 文件浏览

- 点击侧边栏底部的 **"文件"** 标签页打开
- 自动检测 SFTP 可用性，不可用时回退到 SSH Exec 模式
- 使用独立的 SSH 连接进行文件操作，不影响终端会话
- 支持路径导航、目录展开、通配符过滤

### 7.2 上传与下载

| 操作 | 说明 |
|------|------|
| 拖拽本地文件到文件面板 | 上传文件 |
| 双击远程文件 | 下载文件 |
| 右键菜单 | 下载、删除、重命名、新建目录 |

**下载配置：**

- 默认下载目录：`~/Downloads/LyShell/`
- 可为每个服务器配置独立的下载目录
- 启用 "自动创建服务器子目录" 后，下载路径为 `下载目录/服务器名/`
- 下载目录可在设置面板中配置（支持系统目录选择器）

**传输特性：**

- 上传和下载使用 Worker 线程，不阻塞主进程
- 实时显示传输进度和速度
- 下载完成后自动计算 MD5 校验值

### 7.3 下载历史

- 文件管理器的 **"记录"** 标签页可查看下载历史
- 记录包含：文件名、远程路径、本地路径、文件大小、时间、状态、MD5
- 支持重新下载和打开本地文件

## 8. AI Agent

LyShell 内置 AI Agent 快速启动栏，位于侧边栏搜索框下方。

### 预置 Agent

| Agent | 命令 | 图标 | 说明 |
|-------|------|------|------|
| Claude Code | `claude` | 🤖 | Anthropic 的 AI 编程助手 |
| Aider | `aider` | 🤝 | AI 结对编程工具 |
| Copilot CLI | `gh copilot` | 🐙 | GitHub 的命令行 AI 助手 |

### 操作

| 操作 | 说明 |
|------|------|
| 单击 Agent 按钮 | 在新终端中启动该 Agent |
| 右键单击 Agent 按钮 | 编辑 Agent 配置 |
| 单击 "+" 按钮 | 添加自定义 Agent |

### 自定义 Agent

每个 Agent 可配置以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 名称 | 显示名称 | "My Agent" |
| 命令 | Shell 启动命令 | `python -m my_tool` |
| 图标 | Emoji 图标 | 🛠️ |
| 工作目录 | 启动目录 | `/home/user/project` |
| 环境变量 | 额外环境变量 | `API_KEY=xxx` |

启动 Agent 时，LyShell 会创建一个本地终端会话，自动执行 Agent 命令，并应用配置的工作目录和环境变量。

## 9. Python 脚本引擎

LyShell 内置 Python 执行引擎，支持在终端中运行 Python 脚本。

### Python 环境

- 优先使用 `resources` 目录下的便携版 Python
- 未找到时自动使用系统 PATH 中的 Python

### LyShell API

Python 脚本中可以使用 `LyShell` 类提供的 API：

```python
# 获取当前会话信息
session = LyShell.get_current_session()

# 在当前终端执行命令
LyShell.execute("ls -la")

# 向终端发送原始数据
LyShell.send("hello\n")

# 等待特定输出
LyShell.wait_for("prompt$")
```

### 执行环境变量

脚本执行时，以下环境变量自动注入：

| 变量 | 说明 |
|------|------|
| `LYSHELL_SESSION_ID` | 当前会话 ID |
| `LYSHELL_SESSION_TYPE` | 会话类型 (ssh/telnet/serial/local) |
| `LYSHELL_HOST` | 连接主机 |
| `LYSHELL_PORT` | 连接端口 |

### Python 设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用 Python | 开/关 | 开 |
| Python 路径 | 自定义解释器路径 | 自动检测 |
| 默认超时 | 脚本执行超时（秒） | 30 |
| 沙盒模式 | 限制模块导入 | 关 |
| 允许模块 | 沙盒模式下允许的模块列表 | - |

## 10. 浮窗快捷连接

浮窗是一个轻量级的快捷连接面板，可通过全局快捷键随时呼出。

## 11. 数据导入导出

LyShell 支持会话配置和快速命令的导出/导入，并可使用 AES-256-CBC 加密保护。

### 导出

1. 点击侧边栏顶部的 **导入/导出按钮**
2. 选择要导出的会话和快速命令
3. （可选）设置加密密码
4. 点击导出，选择保存位置

### 导入

1. 点击导入/导出按钮，切换到 **"导入"** 标签页
2. 选择之前导出的 JSON 文件
3. 如果文件加密，输入密码
4. 预览并确认导入内容

### 安全说明

- 加密算法：AES-256-CBC
- 含密码的会话建议启用加密导出
- 密码不会明文存储在导出文件中

- **分组 (Group)**：会话所属分组

### 会话操作

悬停会话卡片时显示操作按钮：

| 按钮 | 说明 |
|------|------|
| ✏️ | 编辑会话 |
| 📋 | 复制会话（创建相同配置的新会话） |
| 📌 | 置顶/取消置顶 |
| 🗑️ | 删除会话 |

## 14. 主题与外观

LyShell 采用 VS Code 风格的深色主题，支持以下外观配置：

### 终端主题

## 16. 常见问题

### Q: 连接 SSH 时中文乱码怎么办？

编辑会话，将编码从 UTF-8 切换为 GBK 或 GB2312。

### Q: 串口连接后无输出？

1. 确认串口号和波特率配置正确
2. 检查设备管理器中串口是否被其他程序占用
3. 部分设备需要发送回车键才能激活输出

### Q: 文件管理器不显示？

文件管理器仅对 SSH 会话可用。确保当前活动标签页是 SSH 连接。

### Q: 如何在 Windows 上编译原生模块？

需要安装 Visual Studio Build Tools（勾选 "使用 C++ 的桌面开发" 工作负载），然后运行：

```bash
npm run rebuild
```

如果 `npm run rebuild` 因 Visual Studio 版本过新而失败（如 VS 2026），请使用 `npx node-gyp` 直接编译：

```bash
# 获取 Electron 版本号
ELECTRON_VERSION=$(node -p "require('./node_modules/electron/package.json').version")

# 逐个编译
npx node-gyp rebuild --directory=node_modules/cpu-features --target=$ELECTRON_VERSION --arch=x64 --dist-url=https://www.electronjs.org/headers
npx node-gyp rebuild --directory=node_modules/@serialport/bindings-cpp --target=$ELECTRON_VERSION --arch=x64 --dist-url=https://www.electronjs.org/headers
cd node_modules/node-pty && npx node-gyp rebuild --target=$ELECTRON_VERSION --arch=x64 --dist-url=https://www.electronjs.org/headers && cd ../..
```

### Q: 如何重置 LyShell 配置？

删除配置文件目录下的所有 JSON 文件，重启应用后将恢复默认配置。

### Q: 全局快捷键 Ctrl+Alt+F 不生效？

该快捷键可能被其他应用占用。可以在 LyShell 设置中修改浮窗快捷键。

### Q: 下载的文件保存在哪里？

默认保存在 `~/Downloads/LyShell/` 目录下，可在设置面板中修改下载目录。开启 "自动创建服务器子目录" 后，文件会按服务器名归档。
